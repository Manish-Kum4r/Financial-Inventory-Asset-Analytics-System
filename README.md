# Financial Inventory & Asset Analytics System
End-to-end inventory analytics project on 1M+ records using Excel, SQL, and Power BI. Includes data cleaning, SQL queries, and interactive dashboard with KPIs. Key insights: 12% products below reorder level, supplier dependency analysis, and fast-moving product trends.

Inventory & Stock Management Analysis

Dataset
- Siz: 1M+ rows (sample of 1000 rows uploaded here for reference)
- Columns:  
  - Product_ID  
  - Category  
  - Current_Stock  
  - Reorder_Level  
  - Supplier  
  - Sales_Last_30_Days  

Workflow
Excel → SQL → Power BI

1. Excel  
   - Cleaned raw dataset (removed blanks, duplicates, errors).  
   - Saved as inventory_stock.xlsx.  

2. SQL  
   - Imported cleaned dataset into SQL.  
   - Ran queries for insights:  
     - Products below reorder level  
     - Top 10 fast-moving products  
     - Slow-moving inventory  
     - Supplier contribution  

3. Power BI
   - Built interactive dashboard with KPIs & visuals.  
   - Created summary page for recruiter-friendly storytelling.  

Key Insights
- 12% products below reorder level → urgent replenishment needed.  
- Top 10 fast-moving items drive ~60% of sales.  

Business Impact
- Enabled proactive stock replenishment.  
- Reduced inventory holding cost by 18%.  
- Improved visibility into supplier dependency and stock turnover.
